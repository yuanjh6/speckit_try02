# 快速启动指南：项目管理平台

## 概述
本指南将帮助您快速启动和运行项目管理平台。按照以下步骤，您将能够设置环境、运行应用程序并开始使用看板功能。

## 先决条件
- Node.js 14.x 或更高版本
- npm 6.x 或更高版本
- Git

## 安装步骤

### 1. 克隆仓库
```bash
git clone <repository-url>
cd project-management-platform
```

### 2. 安装依赖
```bash
# 安装后端依赖
cd backend
npm install

# 安装前端依赖
cd ../frontend
npm install
```

### 3. 配置环境
```bash
# 后端环境配置
cd ../backend
cp .env.example .env
# 编辑 .env 文件以设置数据库连接和其他配置

# 前端环境配置
cd ../frontend
cp .env.example .env
# 编辑 .env 文件以设置API端点
```

## 运行应用程序

### 1. 启动后端服务
```bash
cd backend
npm run dev
```
后端服务将在 http://localhost:3001 上运行

### 2. 启动前端应用
```bash
cd frontend
npm run dev
```
前端应用将在 http://localhost:3000 上运行

## 使用指南

### 1. 选择用户
1. 打开浏览器并访问 http://localhost:3000
2. 在用户选择页面，从5个预定义用户中选择一个：
   - 产品经理 (Product Manager)
   - 工程师 (Engineer) x4

### 2. 查看项目列表
1. 选择用户后，您将看到项目列表页面
2. 系统会自动创建3个示例项目

### 3. 使用看板
1. 点击任一项目进入看板视图
2. 您将看到4个列："待办"、"进行中"、"审核中"和"已完成"
3. 每个项目将有5-15个随机分配的任务

### 4. 管理任务
1. **创建任务**：点击"添加任务"按钮创建新任务
2. **移动任务**：拖放任务卡在不同列之间移动
3. **分配任务**：点击任务卡，从下拉菜单中选择分配给哪个用户
4. **添加评论**：在任务卡详情中添加评论

### 5. 管理评论
1. **编辑评论**：点击自己的评论旁的"编辑"按钮修改内容
2. **删除评论**：点击自己的评论旁的"删除"按钮删除评论
3. 注意：您只能编辑和删除自己创建的评论

## 测试场景验证

### 场景1：用户选择和项目列表
- **假设** 用户已从用户列表中选择了他们的个人资料
- **当** 他们查看项目列表时
- **则** 他们能看到所有可用的项目

### 场景2：任务状态更新
- **假设** 用户正在查看项目的看板
- **当** 他们将任务卡从"待办"拖拽到"进行中"时
- **则** 任务状态会相应更新

### 场景3：添加评论
- **假设** 用户正在查看任务卡
- **当** 他们添加评论时
- **则** 该评论对所有团队成员可见

### 场景4：编辑评论权限
- **假设** 用户已发布评论
- **当** 他们编辑自己的评论时
- **则** 评论会成功更新
- **当** 他们尝试编辑其他用户的评论时
- **则** 他们无法这样做

### 场景5：任务分配
- **假设** 用户正在创建或编辑任务
- **当** 他们将任务分配给团队成员时
- **则** 他们只能从5个预定义用户中选择

### 场景6：用户任务高亮
- **假设** 用户正在查看看板
- **当** 他们看到分配给自己的任务时
- **则** 这些任务会以不同的颜色显示

## 故障排除

### 常见问题
1. **无法连接到数据库**：检查 .env 文件中的数据库配置是否正确
2. **前端无法连接到后端API**：检查前端 .env 文件中的API端点配置
3. **端口冲突**：修改 package.json 中的启动脚本以使用不同的端口

### 日志查看
- 后端日志：查看终端中后端服务的输出
- 前端日志：查看终端中前端应用的输出或浏览器开发者工具的控制台

## 停止应用程序
1. 在后端终端按 Ctrl+C 停止后端服务
2. 在前端终端按 Ctrl+C 停止前端应用
