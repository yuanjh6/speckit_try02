## Summary
开发一个项目管理平台，允许用户创建项目、添加团队成员、分配任务、评论以及在看板风格中移动任务。平台将有5个预定义用户（1位产品经理和4位工程师）和3个示例项目。每个任务将有4个标准状态（待办、进行中、审核中、已完成），用户可以在不同列之间拖放任务卡来更新任务状态。任务可以分配给团队成员并添加评论。平台无需登录，作为第一个测试版本。

## Technical Context
**Language/Version**: TypeScript (前端和后端), Node.js 14+
**Primary Dependencies**: React (前端), Express.js (后端), Jest (测试)
**Storage**: SQLite (开发), PostgreSQL (生产)
**Testing**: Jest for unit and integration testing
**Target Platform**: Web browsers (Chrome, Firefox, Safari)
**Project Type**: web - 项目管理平台通常需要Web界面
**Performance Goals**: 响应式UI，任务操作延迟<200ms
**Constraints**: 无登录要求，会话内数据持久化
**Scale/Scope**: 小型项目 - 5个用户，3个项目，每个项目5-15个任务

## Constitution Check
*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

基于宪法文件，以下检查项需要满足：

1. **库优先原则**: 功能应作为独立库开始，库必须自包含、可独立测试和文档化
2. **CLI接口原则**: 每个库都应通过CLI暴露功能
3. **测试优先原则**: 必须采用测试驱动开发（TDD）
4. **集成测试原则**: 需要集成测试来验证新库的合同测试、合同变更、服务间通信和共享模式
5. **可观察性原则**: 需要结构化日志记录确保可调试性
6. **简化原则**: 遵循YAGNI（You Aren't Gonna Need It）原则，从简单开始

- Mark [P] for parallel execution (independent files)
